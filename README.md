# Beat Down - PS2 

This is a C++ reimplementation for Beat Down: Fists of Vengeance - PS2. 

It was mostly a test that I used when experimenting with local/frontier LLMs within assisted reverse engineering and decompilation research

### Build

The project is currently setup such that the original disc contents is extracted into a directory named `raw` and will read the original assets from there. 


Build instructions may come later, if I decide to revisit this title.

### Libs

- [librw](https://github.com/aap/librw)
